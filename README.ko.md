# Anki Card Manager

[ [English](https://github.com/jaewonE/anki-card-manager) | [한국어](https://github.com/jaewonE/anki-card-manager/blob/master/README.ko.md) ]

Anki Card Manager는 `obsidian-to-anki` 마커 블록을 Obsidian 안에서 간결한 접이식 카드로 보여 주고, Vault 전체 카드의 원본 Markdown을 한 화면에서 관리하게 해 주는 확장 프로그램입니다. 버전: **0.1.2**.

## 주요 기능

- 완성된 `<START_ANKI>` / `<END_ANKI>` 블록에서 편집기 선택 영역이 벗어나거나 편집기가 포커스를 잃으면 강조 Callout 형태의 카드로 렌더링합니다.
- 카드가 Markdown 코드 펜스의 유일한 내용이면 바깥 펜스까지 UI로 대체해 빈 펜스가 남지 않게 하며, 해당 카드를 삭제할 때도 전용 펜스를 함께 제거합니다.
- 질문은 항상 표시하고 답변은 접이식 영역에 둡니다. 원형 연필 아이콘(**Edit source**)을 누르면 원문 블록이 나타나고 커서가 이동합니다. 문서 하단 모음에서도 동일하게 사용할 수 있으며, 카드 유형은 답변 상단에 표시합니다.
- 질문 전체를 표시하는 것이 기본값이며, 한 줄로 제한하고 말줄임표로 생략하는 설정을 제공합니다.
- Anki 형태의 카드·별 아이콘을 등록 상태에 따라 파란색/붉은색으로 표시하며, 어두운 테마에서는 더 밝은 색을 사용합니다.
- 전체 가장자리에 균일한 그림자를 두며 어두운 테마에서는 흰색 그림자를 사용합니다. 공백만 사이에 있는 연속 카드는 하나의 그림자로 묶고, 내부 카드는 개별 그림자나 둥근 모서리 없이 얇은 구분선으로 나눕니다. 문서 하단 모음도 같은 형태입니다.
- 기본값은 카드 UI를 원래 위치에 유지하며, 현재 문서의 모든 카드 UI를 문서 하단에 모으는 설정도 제공합니다.
- 한 줄에 `<START_ANKI>`를 입력하면 설정된 카드 유형, 질문·답변용 빈 줄, 해당 구분자와 `<END_ANKI>`를 자동으로 완성합니다. 입력 또는 Enter 시 다음 시작 마커보다 먼저 닫는 마커가 있으면 중복 완성하지 않으며, 인라인으로 적힌 다음 시작 마커도 구분합니다.
- 카드/묶음 바로 뒤에서 Backspace를 누르면 숨겨진 블록을 지우지 않고 원문을 엽니다. 앞쪽 Delete도 보호하며, 일반 텍스트 편집과 명시적으로 선택한 영역의 삭제는 그대로 가능합니다.
- `Cloze` 유형과 `Text:` 구분자를 지원합니다. 빈칸별 독립 공개, 전체 공개/비공개 토글, 답변을 닫을 때 모두 가리기를 제공합니다.
- 자동완성 시 `anki_deck: Inbox`와 `anki_tags: [Inbox]`가 YAML에 없으면 추가합니다. 이 기본값은 설정에서 바꿀 수 있습니다.
- 모든 Markdown 파일을 스캔하여 등록 및 등록 해제 카드를 검색 가능한 표로 보여 줍니다.
- 표에서 원본 위치 열기, 수정, 삭제를 수행하면 해당 Markdown 원문에 직접 반영합니다.
- Anki와 통신하지 않고 등록 상태를 전환합니다. 등록 해제 시 독립된 `<!--ID: ... -->` 줄을 제거하고 마커를 `<ANKI_START>` / `<ANKI_END>`로 바꾸며, 등록 시 원래 마커로 되돌립니다.
- `study/software/sdlc`처럼 계층형 태그를 기준으로 표의 카드를 묶어 볼 수 있습니다.

## 카드 형식

다음 등록 형식을 인식합니다.

```text
<START_ANKI>
Obsidian-Basic
질문(여러 줄 가능)
Back:
답변(여러 줄 가능)
<!--ID: 1775887365861-->
<END_ANKI>
```

카드가 들어 있는 Markdown 파일에는 다음 YAML 속성이 있어야 합니다.

```yaml
---
anki_deck: 개발::정처기
anki_tags:
  - 정처기
---
```

이 플러그인은 `obsidian-to-anki` 형식과 호환되지만 Anki, AnkiConnect 또는 `obsidian-to-anki` 동기화 작업을 직접 실행하지는 않습니다.

### Cloze 카드

카드 유형이 정확히 `Cloze`일 때만 `Back:` 대신 `Text:`를 사용합니다.

```text
<START_ANKI>
Cloze
**UML**이란 무엇인가?
Text:
**UML**은 {{c1::표준화된 객체 지향 모델링 언어}}이다.
- 구성요소: {{c1::사물}}, {{c1::관계}}, {{c2::다이어그램}}
<END_ANKI>
```

각 빈칸에는 불투명한 형광펜 형태의 가리개가 표시됩니다. 같은 번호를 가진 빈칸도 클릭하거나 포커스를 두고 Enter/Space를 누르면 개별적으로 공개됩니다. 카드 유형 옆의 **Reveal all answers / Hide all answers**로 전체를 전환하며, 답변을 닫으면 모두 다시 가려집니다. 공개한 답변에서는 굵은 글씨와 인라인 코드 등 Markdown 서식이 유지됩니다.

제공된 예시의 단일 콜론 형식 `{{c1:답변}}`도 표시할 수 있으나 원문 표기를 자동으로 바꾸지는 않습니다. Anki 호환성을 위해서는 표준 이중 콜론 형식 `{{c1::답변}}`을 사용하십시오. 관리 화면의 편집·등록 전환과 기본 유형을 `Cloze`로 설정한 자동완성은 `Text:`를 유지합니다. 카드를 보거나 빈칸을 공개하는 동작은 노트를 수정하지 않습니다.

## 사용 방법

1. 독립된 줄에 `<START_ANKI>`를 입력합니다. 다음 시작 마커 전에 대응하는 닫는 마커가 없다면 나머지 카드 템플릿과 누락된 YAML 속성이 즉시 추가됩니다.
2. 질문과 답변을 작성한 뒤 편집기 선택 영역을 마커 블록 밖으로 옮기거나 다른 패널로 포커스를 이동해 접이식 카드를 확인합니다. **Edit source**를 누르면 원문으로 돌아갑니다.
3. 왼쪽 리본의 라이브러리 아이콘을 선택하거나 **Anki Card Manager: Open card manager** 명령을 실행해 Vault를 스캔합니다.
4. 검색, 상태 필터, 태그 계층 묶기, 원문 열기, 수정, 등록 전환 및 삭제 기능을 사용합니다.

관리 화면의 수정과 삭제는 Vault 원문을 직접 변경합니다. 특히 여러 카드를 정리하기 전에는 평소 사용하는 백업이나 버전 관리를 유지하십시오. 스캔 후 파일 내용이 달라졌다면 오래된 범위에 쓰지 않고 작업을 중단하므로, 다시 스캔한 뒤 재시도하면 됩니다.

## 명령과 단축키

- **Open card manager**
- **Insert Anki card**

기본 단축키는 지정하지 않습니다. **Settings → Hotkeys**에서 직접 설정할 수 있습니다.

## 설정

- **Card placement:** 카드 UI를 원래 위치에 유지(기본값)하거나 문서 하단에 모읍니다.
- **Single-line titles:** 제목을 한 줄로 제한하고 말줄임표를 표시합니다. 기본값은 꺼짐입니다.
- **Complete start markers:** 카드 자동완성을 켜거나 끕니다.
- **New card defaults:** 카드 유형(`Obsidian-Basic`), 덱(`Inbox`), 태그(`Inbox`) 기본값입니다.

## 개인정보, 네트워크 및 플랫폼 지원

플러그인은 로컬에서만 동작하며 네트워크 요청과 텔레메트리를 사용하지 않습니다. 현재 Vault 안의 Markdown 파일과 플러그인 설정만 읽거나 쓰며 Vault 밖 파일은 읽지 않습니다. 설정은 플러그인 폴더의 `data.json`에 저장됩니다.

`isDesktopOnly`는 `false`입니다. 편집기 카드 UI와 반응형 관리 화면은 Obsidian API와 브라우저 호환 코드로 구현되어 데스크톱과 모바일에서 사용할 수 있습니다.

## 설치

### 수동 설치

1. 일치하는 GitHub Release에서 `main.js`, `manifest.json`, `styles.css`를 내려받습니다.
2. 세 파일을 `<Vault>/.obsidian/plugins/anki-card-manager/`에 복사합니다.
3. Obsidian을 다시 불러온 뒤 **Settings → Community plugins**에서 **Anki Card Manager**를 활성화합니다.

Obsidian Community Plugin Directory 등록이 승인된 이후에는 Community Plugins 화면에서도 설치할 수 있습니다.

## 개발

Node.js 22.13 이상 또는 더 최신 LTS 버전을 사용합니다.

```bash
npm install
npm run lint
npm test
npm run build
```

프로덕션 릴리스 파일은 저장소 루트에 생성됩니다.

`npm test`는 파서 테스트와 실제 CodeMirror DOM 회귀 테스트를 6.38.6 및 6.43.9 버전에서 실행합니다. 최초 렌더링, 위치 251, 포커스 진입·이탈, 펼침 후 높이 측정, 원문 편집, 두 배치 모드, 연속 카드 묶음, 말줄임, Cloze 가리개·초기화·원문 보존, 자동완성 경계, 키보드/네이티브 삭제 보호, 반복 편집 및 확장 해제를 검증합니다. Obsidian 호스트 API는 테스트 대역을 사용하므로 Obsidian 앱 내부 확인을 대체하지는 않습니다.

브라우저 레이아웃은 `npm run test:browser` 실행 후 출력되는 localhost 주소에서 확인할 수 있습니다. 테스트 화면은 샘플 텍스트만 사용하며 Vault 파일을 읽거나 쓰지 않습니다. CodeMirror와 테스트 의존성은 프로덕션 플러그인에 포함되지 않으며, 실제 편집기 런타임은 Obsidian에서 제공합니다.
